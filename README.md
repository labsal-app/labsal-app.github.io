# LabSal Producción

App de uso interno para registrar producción, stock, costos y ventas.

- Funciona en el celular, se puede instalar y anda sin internet.
- Los datos se guardan solo en el dispositivo. Desde **Ajustes → Copia de seguridad** se descarga y se restaura una copia.
- Las copias de seguridad no se suben a este repositorio.
